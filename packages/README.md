# Packages Directory — Shared Modules

Dossier pour les briques partagées de l'écosystème **CDF Wallet** :

- `packages/wallet-core/` : Dérivation mnémonique, gestion de comptes, signature locale
- `packages/blockchain/` : Connecteurs RPC, interfaces EVM, ABIs
- `packages/security/` : Algorithmes de chiffrement AES-GCM / PBKDF2, validations d'adresses
- `packages/tokens/` : Définitions et mathématiques des tokens (CDF, BNB, USDT)
- `packages/shared/` : Utilitaires de formatage, constantes globales, i18n
