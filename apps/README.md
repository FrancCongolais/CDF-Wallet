# Apps Directory — CDF Wallet Multi-Platform Targets

Ce dossier est préparé pour héberger les cibles multiplateformes futures de **CDF Wallet** :

- `apps/web/` : Application Web PWA / Desktop
- `apps/android/` : Application mobile native Android (Kotlin / React Native / Capacitor)
- `apps/ios/` : Application mobile native iOS (Swift / React Native / Capacitor)

Ces applications partageront les packages sous `packages/` (`wallet-core`, `blockchain`, `security`, `tokens`).
